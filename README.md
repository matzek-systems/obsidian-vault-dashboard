# Vault Dashboard

An Obsidian plugin for the vault system with three views and one app:

- **Dashboard**: the operator board (what needs you, overdue work, seats, live threads).
- **Process Status**: the PC's background processes, with Launch and Restart.
- **LWP Call Day**: the call-day view over the CRM.
- **The remote app**: the same board plus your Claude seats on your phone or in a desktop
  browser, over your own Tailscale network. The server lives in `remote-server/` and the
  plugin starts and stops it.

**Setting up the remote app: [`remote-server/README.md`](remote-server/README.md).** That
guide covers Tailscale, the PC, the phone, how to use it, troubleshooting, and, at the
bottom, everything the server depends on.

## Building from source

```
npm install
VAULT_PATH="C:/path/to/your vault" npm run build
```

The build writes `main.js`, `manifest.json` and `styles.css` and copies `remote-server/`
into `<VAULT_PATH>/.obsidian/plugins/vault-dashboard/`. Reload the plugin in Obsidian; the
phone server restarts with it.

## Where things live

- Installed plugin: `<vault>/.obsidian/plugins/vault-dashboard/` (the server is the
  `remote-server/` folder inside it)
- The app's runtime state, never in the vault: `%LOCALAPPDATA%\vault-remote\`
- The data the views and the app render:
  `<vault>/00_System/AI/Claude/System Operations/state/dashboard-data.json`, generated by
  `tools/dashboard/dashboard_data.py` from your roadmaps and session transcripts.
